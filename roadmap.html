Roadmap

Two goals drive every release: build the best keyboard lock on the Mac, and lock the keys so you can love the cat. Below is what's shipped, what's coming, and what's on the radar. Cats Lock is built by one developer and one cat, with releases shaped by customer feedback. If something here matters to you (or something's missing), email meow@catslock.app.

Shipped

Available now on the Mac App Store
  • v1.5.2 (August 4, 2026) — more Smart Detect tuning: fewer false locks from accidental key brushes or fast typing, smarter held-key handling, and no more repeated re-locks after it fires.
  • v1.5.1 (August 1, 2026) — Smart Detect fine-tuning: fewer false locks during normal use of arrow keys and keyboard shortcuts, while still catching a cat on the keys.
  • v1.5.0 (July 20, 2026) — an on-screen lock badge for Stealth Lock and built-in keyboard lock, showing the unlock shortcut and a one-tap Unlock (plus a lock/free trackpad button), so a lock you didn't expect is never a mystery.
  • v1.4.4 (July 16, 2026) — Smart Detect now also catches cats that rest or gently walk on the keyboard, and the "That wasn't my cat" button on auto-locks is easier to spot.
  • v1.4.3 (July 10, 2026) — Smart Detect tuning: far fewer false locks while typing, five sensitivity levels, and an option to ignore single-key holds.
  • v1.4.2 (July 8, 2026) — the lock now fully blocks Cmd-Tab even when Cats Lock is hidden from the Dock, and the main window opens reliably and in front (from the menu bar, at launch, or with Hide from Dock on).
  • v1.4.1 (July 1, 2026) — Smart Detect is now reachable from the menu bar, and locking clears Mission Control first so the lock screen is never stranded behind it.
  • v1.4.0 (June 26, 2026) — Smart Detect (beta): Cats Lock can lock itself when it senses cat-style typing, plus the lock now covers full-screen apps.
  • v1.3.1 (June 22, 2026) — lock the built-in trackpad too when an external mouse is connected, Caps Lock protection, and more reliable Hide from Dock.
  • v1.3.0 (June 17, 2026) — lock the built-in keyboard only while an external keeps working, plus a new app icon.
  • v1.2.1 (June 11, 2026) — Cmd+Tab lock hardening, guaranteed Stealth Lock escape, smoother audio.
  • v1.2.0 (June 8, 2026) — lock function keys (F1-F12), menu bar icon picker.
  • v1.1.2 (June 2, 2026) — Siri voice command compatibility, refreshed app icon with proper Dark and Tinted appearance variants.
  • v1.1.1 (May 20, 2026) — shortcut label fix for non-US keyboard layouts.
  • v1.1.0 (May 19, 2026) — global lock shortcut, customizable shortcut, hide from Dock, prevent sleep while locked, first-time Stealth Lock confirmation.
  • v1.0.0 (May 15, 2026) — initial release on the Mac App Store.
